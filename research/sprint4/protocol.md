**Question.** Does the Sprint-3 synaptic/presynaptic signal represent a direct inherited

indirect family effects or shared UK-Biobank sampling?

## Fixed analytical choices (identical to Sprint 3)

- MAGMA v1.10 (same binary), SNP-wise mean, NCBI37.3 genes with a 10 kb window, 1000 Genomes
  EUR (g1000_eur, 503 people, GRCh37), `snp-exclude=position_mismatch_snps.txt`.
- Gene sets: the full `syngo.setannot`, with `--gene-covar data/sprint4/gene_covariates.txt`
  (byte-identical copy of the Sprint-3 covariates) and
  `--model condition-hide=log_annotation_density,log_LOEUF`. The test is competitive and one-sided.
- **Sign of a set beta.** MAGMA gene statistics come from P-values, so a positive set beta
  means *more association* in set genes, in either allelic direction. It is enrichment
  concordance, not allele-direction concordance. Allele direction is tested at the locus level.
- Input sha256 values (Davies input, MAGMA binary, reference, annotation, covariates, LDetect
  blocks) are in the JSON.

## Gate A — within-sibship direct effect (Howe et al. 2022)

- **Data.** `ieu-b-4837` (sibling) and `ieu-b-4838` (population). Every metadata field above,
  plus the VCF header ID, must match. Otherwise Gate A is NOT_TESTABLE.
- **Access.** Needs `OPENGWAS_JWT`. At freeze time it is ABSENT. No account is created and no
  website download is scripted.
- **Effective N.** N_eff(WF) = N_pop × median over SNPs with 0.05 ≤ AF ≤ 0.95 of
  (SE_pop / SE_wf)². This depends only on the design.
- **Direct-effect fraction under Howe's genome-wide shrinkage.** f = 0.78, per the brief. It
  may be corrected from the Howe 2022 text as a recorded pre-data amendment, but only while no
  within-family value has been read.
- **Power calibration (chosen now, before any within-family value exists).**
  - Method: LD-aware summary-statistic subsampling (PUMAS-style):
    `z_sim = f·√(n/N)·z_obs + √(1 − f²·n/N)·e`, with `e ~ N(0, R)`.
  - The noise `e` is generated from g1000_eur genotypes, independently per LDetect EUR block,
    and aligned to the effect allele.
  - Every replicate runs through the identical MAGMA gene and gene-set pipeline.
  - Pre-data source: Davies at n ∈ {22,593; 9,997; 4,999} × f ∈ {1.0, 0.78, 0}, 40 replicates
    each, seed 20260923, with the same noise draws reused across scenarios.
  - Post-data source (primary once available): the Howe population GWAS subsampled to N_eff(WF).
- **Set classes.**
  - DIRECT_EFFECT_SUPPORTED (P_wf < 0.05).
  - CONCORDANT_BUT_UNDERPOWERED (beta_wf > 0, P ≥ 0.05, and beta_wf not below the 2.5th
    percentile of the f = 0.78 expectation).
  - INCONSISTENT, in two kinds:
    - BEYOND_EXPECTED_NOISE: below that percentile.
    - SIGN_DISCORDANT_WITHIN_NOISE: beta_wf ≤ 0 but inside it. This kind cannot drive PIVOT.
  - NOT_TESTABLE.
  - Adequate power means simulated P(P_wf < 0.05 | f = 0.78) ≥ 0.5.
- **Attenuation.** The ratio beta_wf / beta_pop, with a parametric-bootstrap CI (conservative:
  it ignores the positive correlation between the estimates) and a Fieller CI when
  |beta_pop / SE_pop| > 2.
- **The 159 loci (frozen in the JSON with their lead SNPs).**
  - Lead SNP: the min-P Davies SNP inside the span of the locus's Bonferroni genes ± 10 kb.
  - Harmonisation: by rsID. Strand flips are allowed for non-palindromic SNPs only. Palindromic
    SNPs with AF in [0.40, 0.60] are UNRESOLVED_HARMONISATION.
  - Proxy: r² ≥ 0.8 within 500 kb.
  - Winner's curse: Tweedie correction of the Davies Z.
  - Classes: DIRECT_SUPPORTED, CONCORDANT_UNDERPOWERED, DISCORDANT_WITHIN_NOISE,
    DISCORDANT_BEYOND_NOISE, NOT_TESTABLE.

## Gate B — independent non-UKB evidence (Genes & Cognition)

- **Data.** Only `tma_gwas_gc.txt`, `tmn_gwas_gc.txt` and `tmd_gwas_gc.txt`, md5-checked
  against the Zenodo listing. The `*_meta.txt` and `*_gwas_ukb.txt` files are FORBIDDEN as
  independence evidence, and a test enforces it.
- **Phenotype.** The primary is TMA, labelled EXECUTIVE_FUNCTION, not GENERAL_COGNITION. If the
  source defines the files differently, the alphanumeric condition becomes primary, recorded as
  a pre-data amendment.
- **Direction.** Set from the phenotype definition only. If higher means slower, the
  cognition-aligned z is −z. It is never taken from the data or from NT5DC2.
- **Sets.**
  - INDEPENDENT_SUPPORT (P < 0.05; Bonferroni over 6 sets reported alongside).
  - CONCORDANT_BUT_UNDERPOWERED.
  - INCONSISTENT: below the 2.5th percentile of the n = 9,997 expectation at f_gc_lower
    (the verified rg between the phenotype and general cognition, else 0.5).
  - NOT_TESTABLE.
  - The Davies-subsampled f = 1 expectation is labelled an upper bound.
- **Loci.** G&C_SUPPORTED when the aligned one-sided P < 0.05 in TMA, or the minimum over the
  three phenotypes × 3 is < 0.05. BH-FDR across loci is reported as a confidence measure only.
- **Positive control.** NT5DC2 rs7639267 reproduces the published G&C estimate (same sign,
  |Δbeta| ≤ 0.1·|beta_pub| + 0.001, P within ×2). NT5DC2 stays prenatal-dominant; replication
  does not make it an adult target.

## Survivors (carried to Gate C)

A locus is carried forward if one of these holds:

- **A.** The locus is DIRECT_SUPPORTED in Gate A.
- **B.** The locus is G&C_SUPPORTED in Gate B.
- **C.** It has exceptionally strong prior evidence and a Gate-A locus result of
  CONCORDANT_UNDERPOWERED. Strong prior evidence means both of:
  - a Davies lead P < 1e-15;
  - a non-positional L2G driver.

Other rules:

- NEGR1 and SYT1 are always carried as STRESS_TEST, but they are not survivors unless A, B or C holds.
- NT5DC2 is the positive control.
- None of these select anything: paper counts, top-50 membership, seed status or theory nodes.

## Gate C — variant → adult-brain gene → direction

- **Fine-mapping.**
  - Primary: the Open Targets GWAS credible sets from Sprint 3.
  - Sensitivity: `susie_rss` on Davies (window ± 500 kb, g1000_eur LD, L = 10, coverage 0.95,
    purity 0.5).
  - An LD mismatch is flagged when `estimate_s_rss` > 0.2.
- **QTL data.** eQTL Catalogue brain datasets, adult donors only. Datasets that include
  prenatal or child samples are flagged and excluded from direction.
- **Colocalisation.** `coloc.susie` when both sides have credible sets, otherwise `coloc.abf`.
  - Priors: p1 = p2 = 1e-4, p12 = 5e-6.
  - PP.H4 ≥ 0.8 is strong.
- **Direction rule — UNCHANGED from Sprint 3.**
  - A gene needs ≥ 3 strong gene-level adult-brain eQTL/pQTL colocalisations with ≥ 80%
    polarity-adjusted sign agreement.
  - Rows are counted as in Sprint 3.
  - A secondary dataset-level count is a robustness flag, never a relaxation.
  - NEGR1 (3/4 = 75%) is not re-thresholded.
- **Joint gene/tissue fine-mapping.** FOCUS or TGFM on ≤ 5 multi-gene loci. If infeasible, the
  exact blocker is recorded and no substitute claim is made.

## Decision (exactly one, by precedence)

1. **STOP_CURRENT_HYPOTHESIS:** the PIVOT condition holds in BOTH Gate A and Gate B.
2. **PIVOT:** ≥ 3 of 6 sets are INCONSISTENT (BEYOND_EXPECTED_NOISE) in an adequately powered
   Gate A, or in Gate B with power ≥ 0.5 at f_gc_lower.
3. **RETRY:** all six sets are NOT_TESTABLE in Gate A (access or technical failure).
4. **CONTINUE:** ≥ 1 set is DIRECT_EFFECT_SUPPORTED, AND at least one of:
   - ≥ 1 set has G&C INDEPENDENT_SUPPORT;
   - the G&C locus sign concordance has P < 0.05;
   - ≥ 1 survivor has a direction-resolved adult-brain chain.
5. **ESCALATE:** the synaptic biology survives, but direction is unresolved because the
   adult-brain QTL data are inadequate. The resolving dataset must be named.
6. **RETRY:** anything else that is ambiguous.

**Chemistry gate.** It stays CLOSED unless one gene has all five of:

- independent support;
- credible locus-to-gene evidence;
- adult-brain molecular evidence;
- consistent direction;
- no disqualifying safety or pleiotropy signal.

Even then, the label is CAUSAL_TARGET_ADJUDICATION_CANDIDATE, never "drug target".

## Never

- NOT_TESTABLE is never reported as NO_EFFECT.
- EA is never direct cognition evidence.
- A UKB-containing file is never counted as G&C independence.
- No new pathways, tournament or weighted score are introduced.
- Theory nodes select nothing.
- Animal-memory data are never used to rescue a human locus.

### Implementation note — 2026-09-24T08:48Z approx. (Sprint 5A; NOT a rule change; written before any within-family association value was analysed)

The token was supplied by the user, and the data were fetched on 2026-09-24. At that point these facts were known:

- The Howe 2022 GWAS-VCFs carry **no AF field**.
- The frozen rules use ALT frequency in two places:
  - the effective-N filter, 0.05 ≤ AF ≤ 0.95;
  - the palindromic-SNP rule, where ALT frequency in [0.40, 0.60] means UNRESOLVED_HARMONISATION.

**Implementation.** AF is taken from the project's own LD reference: 1000G EUR, 503 individuals (`pipelines/sprint5a/g1000_freq.py`).

- The reference frequency is matched to each VCF's ALT allele by rsID and allele.
- It is inverted when the reference A1 is the VCF REF.
- It is set to NaN when the alleles do not match.
- NaN AF excludes a SNP from the effective-N median.
- A palindromic lead with NaN AF is UNRESOLVED_HARMONISATION (conservative).

**Winner's-curse expectation.** The frozen KDE-Tweedie estimator is used exactly as prespecified for the primary locus classes. Sprint 5 amendment A2 found it numerically unstable in the tail, so the same classes computed with the stable EB estimator are reported alongside as a disclosed sensitivity. They never replace the primary classes.

**Code fixes** (plumbing only):

- OpenGWAS API v4: POST `gwasinfo` replaces the GET `gwasinfo/{id}` metadata call.
- `Path.with_suffix` bug: the gene-set output path dropped ".syngo".

**Disclosure.** While checking VCF parsing, the first 3 rows of each file were printed (chromosome 1, positions 49,298–86,028). None is a cognition locus lead SNP. No thresholds, sets, loci or classes changed.
